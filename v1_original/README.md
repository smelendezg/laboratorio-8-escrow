# Versión 1 – Código original

Ejemplo entregado por el docente. Un solo comprador, una sola pasarela, un solo
vendedor y una sola transacción guardada en el diccionario global `transaccion`.
Los participantes actúan por tiempos fijos (`asyncio.sleep`) y los eventos solo
tienen `tipo` y `origen`.

```bash
python3 EscrowV1.py
```
